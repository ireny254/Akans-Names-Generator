# Akan Name Generator

**Akan Name Generator** is a simple web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender. Akan names come from Ghanaian culture, where children are named according to the day of the week they were born. This project helps users find their corresponding Akan name based on their birthdate and gender.

## Features

- **Day of the Week Calculation**: The app calculates the day of the week based on the user's birthdate.
- **Akan Name Assignment**: Based on the calculated day of the week, it assigns a male or female Akan name.
- **Input Validation**: Ensures that users provide valid dates and select a gender.
- **Simple and User-Friendly Interface**: A clean, easy-to-use web interface for users to input their birthdate and gender.

## Technologies Used

- **HTML**: For structuring the webpage.
- **CSS**: For styling the page and ensuring a clean, responsive layout.
- **JavaScript**: For the logic behind calculating the day of the week and assigning the corresponding Akan name.

## How to Use

1. Open the `index.html` file in your browser.
2. Enter your birthdate (day, month, and year).
3. Select your gender (male or female).
4. Click on "Get Akan Name" to see your corresponding Akan name.
5. If the input is invalid, an alert will prompt you to correct it.
